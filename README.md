# Mehmet Ayaz

I'm building [Portotify](https://portotify.com), decision governance infrastructure for consequential AI and automated systems.

My work focuses on the boundary between a decision and the external effect it is allowed to create.

Current areas of work:

- Runtime decision governance
- Authorization and authority boundaries
- Governed execution
- Durable decision evidence
- Agentic and physical AI governance

I’m particularly interested in systems where being capable of an action is not the same as being authorized to perform it.
